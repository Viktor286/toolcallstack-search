# Contributing

## Setup

Requires Node 24 and pnpm. Postgres is needed only for the database-backed tests and features.

```sh
pnpm install
cp .env.example .env          # add at least one provider key to try real searches
createdb toolcallstack_search            # optional
pnpm dev                      # gateway on :4310, dashboard on :4311
```

## Before opening a pull request

```sh
createdb toolcallstack_search_test       # once
TEST_DATABASE_URL=postgres://localhost:5432/toolcallstack_search_test pnpm check
```

`pnpm check` runs oxlint, the oxfmt format check, the TypeScript check and the tests. Without
`TEST_DATABASE_URL` the database tests are skipped; CI runs them. `pnpm fmt` fixes formatting.

Tests never call a real provider: the gateway takes its HTTP transport as a dependency and the
tests pass a fake one. `pnpm smoke` is the only command that spends provider credits.

## Adding a search provider

1. Copy a file in `apps/gateway/src/providers/` (`tavily.ts` is a good template). A provider is
   two pure functions, `buildRequest` and `parseResponse`, plus what it supports, `notes` for
   callers and, optionally, default `limits`, `pricing` and a `balance` endpoint.
2. Register it in `apps/gateway/src/providers/index.ts`.
3. Add cases to `apps/gateway/test/providers.test.ts` using a real response from the provider,
   trimmed, with any personal data removed.
4. Give it a colour slot in `apps/dashboard/src/lib/providers.ts`.

A unified parameter the provider cannot honour must not be sent in a different meaning. Leave it
out of `features` and the gateway reports it to the caller as a warning.

## Conventions

- The gateway has no build step; Node runs the TypeScript sources, so only erasable TypeScript
  syntax is allowed.
- Never log or store a provider API key. Anything a caller passes in `options` is redacted before
  it reaches the call log (`redact` in `apps/gateway/src/util.ts`).
- Files under `apps/dashboard/src/components/ui/` are generated by shadcn/ui; change them through
  its CLI rather than by hand.
